## 三、剩余任务（Task 8–14）

### Task 8: 答案生成和引用真实性校验

**文件**：citation/ 和 query/ 包  
**核心接口**：
```java
public record Citation(String chunkId, String quote) {}
public record GeneratedAnswer(String text, List<Citation> citations) {}
public interface AnswerGenerator {
    GeneratedAnswer generate(String query, List<RetrievalCandidate> evidence);
}
```
**要点**：
- CitationValidator 纯函数校验：chunkId 必须在证据集合中、quote 必须是 source content 子串（NFKC + 空白折叠）
- SpringAiAnswerGenerator 使用 `@ConditionalOnBean(ChatModel.class)`，没有时用 DisabledAnswerGenerator 返回 `GENERATION_UNAVAILABLE`
- Prompt 明确：只能基于 evidence、每个结论引用 chunkId、quote 逐字、证据不足返回空答案

### Task 9: Spring AI 查询改写适配器

**文件**：rewrite/ 包  
**核心接口**：
```java
public interface QueryRewriter {
    Optional<String> rewrite(String originalQuery, String failureReason);
}
```
**要点**：
- pom.xml 加 `spring-ai-rag` 依赖
- 使用 `RewriteQueryTransformer`，Prompt 要求保留原意、补足关键词、不回答、只返回一个改写
- 模型异常降级为 empty，改写超过 1000 字符拒绝

### Task 10: 一次二次检索的公共查询编排

**文件**：query/ 包（RagQueryService、RagQueryCommand、RagQueryResponse 等）  
**核心接口**：
```java
public record RagQueryCommand(Long clientAppId, String query, int finalLimit) {}
public enum RagQueryDecision { ANSWERED, NO_RELEVANT_KNOWLEDGE_BASE, INSUFFICIENT_EVIDENCE, INVALID_CITATION, GENERATION_UNAVAILABLE }
```
**有限状态机**：
```
ROUTE → RETRIEVE_1 → ASSESS_1
  ├─ sufficient → GENERATE → VALIDATE
  └─ insufficient → REWRITE
       ├─ no rewrite → INSUFFICIENT_EVIDENCE
       └─ rewritten → RETRIEVE_2 → ASSESS_2 → GENERATE → VALIDATE
```
**要点**：
- RetrievalRequest 增加 SearchScope 和 attemptNo
- HybridRetrievalService 关键词和向量检索使用同一 scope
- 只允许一次改写重试

### Task 11: 故障分类、回归数据集和指标

**文件**：evaluation/ 包  
**故障分类**：NO_ROUTE_FALSE_NEGATIVE、ROUTE_FALSE_POSITIVE、RETRIEVAL_MISS、RERANK_MISS、FALSE_ACCEPT、FALSE_REFUSAL、INVALID_CITATION、MODEL_FAILURE、INDEX_FAILURE  
**指标**：Route Recall@3、Retrieval Hit@10、MRR、Refusal Precision/Recall、Citation Validity、Rewrite Recovery Rate、P50/P95 延迟  
**门禁**：Route Recall@3 >= 0.95、Retrieval Hit@10 >= 0.90、Refusal Precision >= 0.95、Citation Validity == 1.00  
**数据集**：30 条 JSONL，覆盖路由/无知识库/证据不足/引用/改写命中

### Task 12: 暴露稳定的公共 RAG API

**文件**：query/RagQueryController.java  
**端点**：`POST /api/v1/rag/query`  
**请求**：`{"query":"预算如何审批","finalLimit":8}`  
**HTTP 状态**：200（业务拒答也 200）、401（认证失败）、400（非法参数）、503（GENERATION_UNAVAILABLE）  
**要点**：Controller 只取 clientAppId、校验参数、调 Service、映射 DTO，不执行路由/阈值/改写

### Task 13: 扩展 Trace、阶段进度和可诊断故障

**文件**：V6 迁移、RetrievalStage、QueryTraceEntity、QueryTraceDetail  
**新增阶段**：ROUTE_PROFILE、ROUTE_VERIFY、EVIDENCE_GATE、QUERY_REWRITE、CITATION_VALIDATE  
**Trace 字段**：clientAppId、originalQuery、effectiveQuery、attemptCount、profileShortlistJson、selectedKbIdsJson、evidenceDecision、failureCode、citationValid

### Task 14: 真实集成、覆盖率和发布门禁

**文件**：integration/ 测试包、Testcontainers  
**要点**：
- Testcontainers MySQL + Elasticsearch
- Embedding/Rerank/AnswerGenerator 用确定性测试替身
- JaCoCo 门禁：核心包 LINE=1.00/BRANCH=1.00，全仓 LINE>=0.95/BRANCH>=0.90
- `mvn clean verify` 全部通过
