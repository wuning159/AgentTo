# RAG 可观测交互与 Word 切分优化设计

## 目标

本次只处理四件事：让检索结果更容易看懂、让 Trace 不再把“未进入精排”和“精排失败”混在一起、让文档入库过程可以实时看到，以及把 Word 从一段一片调整为按标题和段落组合切分。

## 本次范围

- 修改 RAG 管理端的召回实验室、检索 Trace 和文档上传进度展示。
- 修改 DOCX 的解析顺序和切分规则。
- PDF、Excel 的解析与切分规则保持不变。
- 不增加语义切分，不调用大模型判断段落关系。
- 不新增后端推送通道，入库进度继续使用现有任务查询接口轮询。

## 1. 检索 Trace

当前 Trace 会保存融合阶段产生的全部候选，但只有前 `rerankLimit` 条会进入 Rerank，只有前 `finalLimit` 条成为最终结果。因此，表格中出现空的 Rerank 和 Final，不代表 Rerank 服务没有运行，而是该候选没有进入对应阶段。

页面调整为两个视图：

- 默认打开“最终结果”，只显示 `finalRank` 不为空的候选，按照最终排名排序。
- “全部候选”保留融合阶段的完整记录，用于技术排查。
- 全部候选中，空的 Rerank 不再只显示横线，而是显示“未进入精排”。
- 如果整次检索发生 Rerank 降级，继续显示现有降级原因。
- 各阶段耗时继续保留，便于观察 Embedding、关键词、向量、融合和精排耗时。

这样既不会让普通查看者误以为数据异常，也不会丢掉技术管理员需要的完整过程。

## 2. 召回实验室

召回实验室执行检索后，在当前页面直接展示最终命中内容，不要求再打开 Trace 才能看到正文。

每条结果至少展示：

- 最终排名；
- 切片标题或章节；
- 命中的正文内容；
- 文件、页码、章节、Sheet 或行号等已有来源信息；
- Keyword、Vector、RRF 和 Rerank 得分；
- 本次检索的 Trace 入口。

没有结果时显示明确的空结果提示；检索发生降级时，在结果上方显示原因，但仍展示可用结果。

关键词、向量、融合、精排和最终结果数量改为中文说明，并收进默认折叠的“高级检索参数”。默认值仍为 `20 / 20 / 30 / 15 / 8`，普通检索只需要输入问题并执行。

## 3. 文档入库进度

上传成功后打开入库任务抽屉，固定展示完整七阶段：

`存储 → 解析 → 清洗 → 分块 → 向量化 → 索引 → 完成`

页面每 1.5 秒查询一次现有任务接口，并根据任务状态更新：

- 已完成：绿色节点，显示耗时和处理数量；
- 当前执行：高亮节点和动态处理中状态；
- 尚未执行：灰色节点；
- 执行失败：当前节点标红，显示错误信息，后续节点保持未执行；
- 全部完成：整条进度线完成，并刷新文档列表。

进度展示使用固定节点，不再只渲染后端已经完成的阶段。这样即使某个阶段耗时较长，也能看出当前停在哪一步、后面还有哪些步骤。

## 4. Word 解析和切分

### 4.1 文档结构

- 按 DOCX 正文中的真实顺序读取标题、普通段落和表格，不再先读取所有段落、再读取所有表格。
- 根据 Word 的“标题 1、标题 2、标题 3”等样式维护标题路径。
- 相邻正文只有在标题路径相同的情况下才能组合，跨标题时必须结束当前切片。
- 表格不与正文段落合并；遇到表格前先结束当前正文切片，表格继续按行切分并保留所在标题路径。

### 4.2 普通段落组合

- 目标长度为 500 字符，最大长度为 800 字符，继续由现有配置控制。
- 按原顺序向当前切片追加完整段落。
- 当前切片达到目标长度后结束。
- 如果追加下一段会超过最大长度，先结束当前切片，再从下一段开始。
- 普通段落不从中间截断，最后不足目标长度的内容仍保留为一个有效切片。

### 4.3 超长段落

单个段落超过最大长度时依次使用以下规则：

1. 按换行以及 `。！？；` 拆成完整句子并重新组合；
2. 单句仍然过长时，按 `，、：` 等次级标点拆分；
3. 仍然超过最大长度时，最后才按字符强制截断；
4. 超长段落产生的相邻切片可复用上一片末尾的完整句子，重叠量不超过现有 `overlapChars` 配置。

这套规则是确定性的结构和长度切分，不使用 Embedding、LLM 或语义相似度判断。

### 4.4 切片来源信息

每个 Word 切片继续保存并补全：

- 标题路径；
- 起止段落号；
- 内容块类型；
- 表格编号和起止行号；
- 切片顺序、文件版本和内容哈希。

## 异常处理

- Word 没有标题样式时，全文按顶层正文处理，仍可按段落组合。
- 空段落不进入切片。
- 无法识别的自定义标题样式先作为普通段落处理，不在本次增加复杂推断。
- 某次入库失败后，页面保留已完成阶段、失败阶段和错误信息。
- Rerank 只返回部分结果时，最终结果按实际返回内容展示，完整候选仍保留在 Trace 中。

## 验收标准

- Trace 默认列表不再出现没有最终排名的候选；切换后可以查看全部候选。
- 全部候选中的空 Rerank 明确标记为“未进入精排”。
- 召回实验室执行后能在当前页面看到实际命中的文本和来源信息。
- 上传 DOCX 后可以看到七阶段进度动态变化，并能显示成功或失败结果。
- 同一标题下的短段落可以组合，跨标题段落不会组合。
- 超长段落优先按完整句子切分，所有切片均不超过最大长度。
- Word 表格与段落按原文顺序处理。
- 现有 PDF、Excel 行为不发生变化。
