# 后端基础工程实施计划

> 归档说明：本计划已经被 `docs/superpowers/plans/2026-07-16-agentto-backend-phase-0-foundation.md` 替代，不再执行。保留本文仅用于回看早期搭建过程。

> **执行方式：** 当前会话内直接执行。每项功能先写测试并确认失败，再补最小实现，最后运行完整测试。

**目标：** 建立一个按真实中间件和模型服务配置运行的 Spring Boot 后端基础工程，为后续业务接口开发提供稳定入口。

**架构：** 单个 Maven 项目，按业务模块分包。正式工作流通过 `WorkflowGateway` 隔离，本地暂用内存实现。正常运行和基础设施集成测试均连接阿里云隔离资源，不使用内存数据库替代 MySQL。

**技术栈：** Java 21、Spring Boot 4.0.x、Spring AI 2.0.0、Spring MVC、Spring Data JPA、Flyway、MySQL、JUnit 5。

## 全局约束

- 基础包名为 `com.agentto.platform`。
- 正常运行环境缺少中间件地址、账号或模型密钥时直接报告缺少的配置，不使用伪造服务兜底。
- 不在代码或配置中写入真实密码、Token 和模型密钥。
- 业务模块不能直接依赖 Flowable 或公司工作流 SDK。
- 数据库结构只通过 `src/main/resources/db/migration` 修改。
- API 前缀统一使用 `/api/v1`。
